# Task: SCRUM02-F004-UI-001 — Post-resolution feedback form

## Objective
Enable submitters to rate and review resolved complaints.

## User Story
> **As a submitter, I want to rate and comment on a resolved complaint, so that I can share my experience.**

## Acceptance Criteria
- **AC1**: Given complaint status is Resolved, when the submitter opens it, then a feedback form is available.
- **AC2**: Given the submitter submits a rating, when processed, then feedback is saved and the form becomes read-only.

## Dependencies
- Feedback Capture API (`SCRUM02-F004-BE-001`)
