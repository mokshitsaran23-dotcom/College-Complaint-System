# Task: SCRUM02-F004-UI-002 — Admin reporting dashboard

## Objective
Empower administrators to view complaint volume and recurring issue reports for proactive campus planning.

## User Story
> **As an admin, I want to view reports on complaint volumes and recurring issues, so that I can plan maintenance proactively.**

## Acceptance Criteria
- **AC1**: Given an admin opens the dashboard, when it loads, then summary charts/tables of complaint data are displayed.

## Dependencies
- Reporting/Aggregation API (`SCRUM02-F004-BE-002`)
