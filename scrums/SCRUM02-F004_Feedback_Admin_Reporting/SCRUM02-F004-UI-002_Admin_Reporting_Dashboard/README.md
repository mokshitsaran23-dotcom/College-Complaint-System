# SCRUM02-F004-UI-002: Admin Reporting Dashboard

## Overview
Executive dashboard displaying aggregated complaint metrics, department breakdowns, recurring issue hot spots, resolution time KPIs, and satisfaction score cards.

## Standalone Setup & Testing
```bash
npm test
```

## Assumptions Made
1. **Assumed Metric Set**: Volume by Category, Distribution by Department, Hot-spot Locations, and Overall Satisfaction Score.
2. **CSV Export**: Includes button to download raw aggregated summary data as CSV.
