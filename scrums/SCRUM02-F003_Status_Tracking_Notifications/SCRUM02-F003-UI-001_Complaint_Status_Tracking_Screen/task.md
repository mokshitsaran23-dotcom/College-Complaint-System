# Task: SCRUM02-F003-UI-001 — Complaint status tracking screen

## Objective
Provide real-time transparency into complaint progress via visual timeline and status badges.

## User Story
> **As a student, I want to view the real-time status of my submitted complaint, so that I know its progress without calling the office.**

## Acceptance Criteria
- **AC1**: Given a submitter opens their complaint, when the page loads, then current status and a history timeline are displayed.

## Dependencies
- Status API & History Data Store (`SCRUM02-F003-BE-001` / `DB-001`)
